SmartATS - AI-Assisted Applicant Tracking System

June 14, 2026

AI Recruitment & Pipeline Automation

Gemini CV Parsing • pgvector Semantic Search • Live GitHub Enrichment

SmartATS is a full-stack, AI-assisted Applicant Tracking System engineered to streamline end-to-end recruitment pipelines. When candidates apply via the public careers portal, the ingestion pipeline utilizes Google Gemini to parse and extract structured competencies, experience timelines, and contact profiles directly from uploaded PDFs into Azure Blob Storage without requiring candidate account creation.

Candidate discovery implements a strict two-stage retrieval strategy: mandatory technical competencies are evaluated first through hard filtering gates to prevent unqualified applicants from outranking criteria, followed by semantic ranking powered by multilingual-e5-base dense vector embeddings evaluated natively inside PostgreSQL using pgvector. A background enrichment service asynchronously mines public GitHub telemetry to synthesize candidate skill profiles, streaming real-time analysis progress to recruiters over persistent WebSockets.

Governance, Panel Consensus & Scheduling

Default-Deny ABAC • Anti-Bias Redaction • Sweep-Line Calendar Coordination

Engineered with privacy and fairness by design, the backend enforces Attribute-Based Access Control (ABAC) at the API egress boundary. Candidate Personally Identifiable Information (PII) is masked dynamically for technical review leads (tech_lead role) to ensure screening integrity, while bias-sensitive demographics (gender, race, age) are strictly redacted across all roles. To eliminate candidate enumeration risks, non-panel reviewers receive a stealthy 404 Not Found response instead of 403 Forbidden.

The hiring workflow incorporates distributed panel governance, advancing candidates only upon reaching an 80% consensus threshold calculated strictly on the server. Once approved, a sweep-line interval intersection algorithm analyzes Google Calendar free/busy schedules across all panel members to identify optimal interview slots, automatically dispatching calendar invites and notifications through Slack webhooks.
